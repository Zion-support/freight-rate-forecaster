# Freight Rate Forecaster

**Zion Freight Rate Forecaster** — lane-level freight rate forecasts and tender-timing recommendations across modes.

> Part of the **Zion AI App Network** — see [ZION_APP_NETWORK.md](./ZION_APP_NETWORK.md) for the full mesh of interlinked apps.

Live app: https://ziontechgroup.com/freight-rate-forecaster/

## ✨ Features
- **Lane-level forecasts** — per-lane rate outlook for truckload, LTL, ocean and air.
- **Tender timing** — recommends when to tender, spot-buy or wait.
- **Carrier benchmark** — your rates vs. market percentiles.
- **Budget scenarios** — next-quarter freight spend under rate volatility.
- **Alerting** — notifies when a lane breaches thresholds.
